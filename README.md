Flingebook - How to Use
  https://replit-design-project--devlopermman43.replit.app/
Flingebook is a private access slot booking system.
You can book hourly private access slots and receive an access code after payment.

========================================
HOW TO BOOK
========================================

1. Open the booking website:
   replit://repl/@devlopermMan43/Replit-Design-Project

2. Select your preferred date and time slot (hourly slots available for the next 5 days).

3. You can select multiple slots. Consecutive slots will get only one access code

5. Complete the payment using Razorpay (UPI / Cards).

6. After successful payment, you will receive your Access Code on the success page.

========================================
HOW TO USE THE ACCESS CODE
========================================

Desktop / Laptop Users:
- Install the Chrome Extension from:
 https://github.com/devloperman41/Flingster_slot_booking/blob/main/Flingster-Access-Extension.zip
- Open the extension
- Paste the Access Code
- Start using the service

Mobile Users:
- Open the Exo App
- Paste the Access Code
- Start using the service

========================================
IMPORTANT NOTES
========================================

- Access code is valid only during the booked time window.
- Save your access code carefully. It may not be shown again.
- Price: ₹55 per slot
- No refund if the access code has already been used.
- For any issues, contact support through the website.

========================================
SUPPORT
========================================

If you face any problem with booking or access code, please contact support from the website.
